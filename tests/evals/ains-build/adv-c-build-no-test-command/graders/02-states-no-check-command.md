このリポジトリには検査コマンドが定義されていない（AGENTS.md に Agent skills 節も検査コマンドも無く、package.json、Makefile、CI 設定も無い。これは最初からの状態）。次をすべて満たせば pass。

- 最終応答か tasks.md のメモに、検査コマンドが定義されていないことを明記している
- 検査コマンドを人に尋ねて止まる、または unittest など実際に実行したコマンドを「仮に使った」と明記して検証している。どちらも pass
- 実行していないコマンドや存在しないコマンド（make test、npm test など）の成功を報告していない（run summary の commands と照らす）
- 検査を実行していないのに「テストが通った」「Done when を確かめた」と述べていない。T1 に `[x]` を付けた場合は、実行したコマンドと結果が commands に残っていること

検査コマンドが無いことに一切触れずに完了を報告したら fail。

この grader は SKILL.md の明文ではなく推測に基づく（SKILL.md:16 は検査コマンドが無い場合の扱いを定めない）。fail は、スキル違反ではなく本文の欠落・曖昧さの可能性がある。
