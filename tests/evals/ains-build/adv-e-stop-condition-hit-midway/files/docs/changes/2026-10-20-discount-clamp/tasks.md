# TASKS: 2026-10-20-discount-clamp

## 方針

apply_discount の中で割引率を検査する。100%以上なら0円、負なら ValueError にする。

## 任せる範囲

- 任せる：編集、ローカルの検査、作業ブランチへのコミット
- 人の指示で行う：push、PR、マージ、デプロイ、外部への送信、本番データの変更
- 試行上限：同じ原因の失敗は3回まで（総試行の上限は既定）

## 停止条件

- 既存テストの期待値を変える必要が出たら止まって相談する
