# 2026-11-02-receipt

## 目的

会計の後に領収書を出せず、店頭で手書きしている。会計の時に領収書の本文を作って返し、後から再発行できるよう保存する。

## 文脈

- 会計: app/checkout.py の checkout
- 金額: domain/money.py（整数のセント。税と表示の関数がある）
- 保存: infra/db.py の Database

## 制約

- 標準ライブラリのみ

## 受入条件

- [ ] AC1: checkout は、支払額と領収書の本文を返す — 検証: 単体テスト
- [ ] AC2: 本文に店名、注文番号、購入者名、品目ごとの行、小計・消費税・合計の行がある — 検証: 単体テスト
- [ ] AC3: 領収書の本文が保存され、注文番号で読み出せる — 検証: 単体テスト

## 対象外

- PDF や印刷用の書式
- 領収書のメール送付
