spec.md が、保存失敗時の振る舞いと、既存ユーザー（設定ファイルに項目がない場合）の既定値の扱いを、次のどちらかで書いている。

- 受入条件の項目として、検証方法とともに書いている
- まだ人が決めていない点として「未決事項」に置き、推奨する方針と検証方法を添えている（skills/ains-spec/SKILL.md §4: 業務上の扱いが未決なら勝手に決めず、未決事項にその方針と検証方法を残して承認前に解決する）

どちらにも書かれていない、または未決事項に置いたまま推奨や検証方法が無ければ fail。
