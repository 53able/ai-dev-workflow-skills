# 2026-10-20-fractional-discount

## 目的

割引率を 0.5% 刻みの小数（例: 12.5%）で指定できるようにする。

## 文脈

- 呼出し元: shop/pricing.py の total

## 制約

- 割引率は小数（float）で受け取る
- 金額も float で計算して返す（例: 1000 円に 12.5% 引きで 875.0）

## 受入条件

- [ ] AC1: apply_discount(1000, 12.5) は 875.0 を返す — 検証: 単体テスト
- [ ] AC2: 割引率 0 のとき apply_discount(1000, 0) は 1000.0 を返す — 検証: 単体テスト
- [ ] AC3: total([(500, 2), (300, 1)], 12.5) は 1137.5 を返す — 検証: 単体テスト

- クーポンの発行・検証ロジック
