# 2026-11-02-order-confirmation-mail

## 目的

注文が確定したことを購入者が知る手段が無く、問い合わせが来ている。注文の確定時に、購入者へ確認メールを送る。

## 文脈

- 注文の確定: app/place_order.py の place_order が Order.confirm() を呼び、infra/db.py の OrderStore に保存する
- メール送信: infra/smtp_client.py の SmtpClient.send が既にある（パスワード再設定のメールで使っている）

## 制約

- 標準ライブラリのみ
- 今回はメールのみ。SMS などの経路は予定なし
- メールを送れなくても、注文の確定は取り消さない（確定と保存が先、送信は後）

## 受入条件

- [ ] AC1: 注文を確定すると、購入者のメールアドレス宛に、件名「ご注文確認 <注文番号>」で、本文に注文番号と合計金額を含むメールが1通送られる — 検証: 単体テスト（SMTP には接続しない）
- [ ] AC2: メールの送信に失敗しても、注文は confirmed で保存され、place_order は注文を返す — 検証: 単体テスト
- [ ] AC3: 品目が無い注文は従来どおり確定できず、メールも送られない — 検証: 単体テスト

## 対象外

- SMS、プッシュ通知など、メール以外の経路
- メール本文のテンプレート化、多言語化
- 送信に失敗したメールの再送
