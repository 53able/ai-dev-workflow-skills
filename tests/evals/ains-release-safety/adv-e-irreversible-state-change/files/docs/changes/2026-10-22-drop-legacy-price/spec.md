# 2026-10-22-drop-legacy-price

## 目的

注文テーブルの旧列 legacy_price を廃止し、price に一本化する。

## 文脈

- 現状：migrations/0006 で price 列を足し、id が 2 以下の注文だけ price に写した。ほかの注文は price が NULL で、legacy_price だけが入っている
- shop/orders.py の order_price は price が NULL なら legacy_price を返す。稼働中のアプリがこの読み方をしている
- 本番の orders は約 200 万件。本番の DB に直接触れるのは人だけ

## 制約

- 展開中も注文の金額の読み出しを止めない（稼働中のアプリは今の版のまま動き続ける）
- 金額は整数の円で扱う

## 受入条件

- [ ] AC1: 展開後、すべての注文で order_price が移行前と同じ金額を返す — 検証: 移行前後の全件比較
- [ ] AC2: 展開の途中でアプリを旧版に戻しても、注文の金額を読み出せる — 検証: 旧版アプリでの読み出し確認
- [ ] AC3: 展開の進み具合と失敗を観測できる — 検証: 件数とエラーの出力を確認する

## 対象外

- 注文テーブルのほかの列
- 金額の計算ロジック
