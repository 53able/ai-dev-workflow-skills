# 2026-11-01-invoice-rounding

## 目的

請求書の税額と、注文で計算した税額が1〜2円ずれ、問い合わせが来ている。税の端数処理を明細ごとの切り捨てに揃え、請求書と注文の金額を一致させる。

## 文脈

- 税と合計: shop/order.py の Order
- 請求書: shop/invoice.py の build_invoice

## 制約

- 金額は整数の円で扱う（浮動小数点を使わない）

## 受入条件

- [ ] AC1: 税は明細ごとに1円未満を切り捨て、その合計を注文の税額とする — 検証: 単体テスト
- [ ] AC2: 請求書の合計は Order の支払額と一致する — 検証: 単体テスト
- [ ] AC3: 送料にも税を掛け、請求書と注文で同じ額にする — 検証: 単体テスト

## 対象外

- 税率の変更、軽減税率
- 過去の請求書の再発行
